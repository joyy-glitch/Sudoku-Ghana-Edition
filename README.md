# AdinkraDoku

A web-based puzzle game that teaches Ghanaian children (ages 8–14) Adinkra symbols and their meanings through sudoku-style logic puzzles.

## Problem
Many Ghanaian children see Adinkra symbols every day without knowing their names or meanings. Cultural education is often memorisation-based, which children find boring.

## Users
- Children: play puzzles, learn symbols, take quizzes
- Teachers: create a class and track students' progress

## Built with
HTML, CSS, JavaScript, PHP, MySQL
